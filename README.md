## Key Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has a named Project Manager and Product Lead
- **Data-informed decisions**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and learning

## How to Use This Documentation

1. **For Project Initiation**: Follow the [Project Initiation Guide](docs/octoacme-project-initiation.md) to validate and authorize work.
2. **For Project Planning**: Use the [Project Planning](docs/octoacme-project-planning.md) guide to create actionable backlogs and timelines.
3. **For Day-to-Day Execution**: Reference the [Execution & Tracking](docs/octoacme-execution-and-tracking.md) guide for team rhythm and workflows.
4. **For Managing Risks**: Consult the [Risk Management & Communication](docs/octoacme-risks-and-communication.md) guide to identify and escalate blockers.
5. **For Release Readiness**: Follow the [Release & Deployment Guide](docs/octoacme-release-and-deployment.md) to ensure safe, reliable releases.
6. **For Continuous Improvement**: Use the [Retrospective & Continuous Improvement](docs/octoacme-retrospective-and-continuous-improvement.md) guide to capture learnings and drive action items.
